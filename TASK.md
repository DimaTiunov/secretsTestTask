# Задание

## Контекст

Это приложение `orders` для Webasyst: заказы в личном кабинете клиента и просмотр заказов сотрудником в бэкенде. Код сгенерировал AI-ассистент по задаче «сделай приложение заказов для личного кабинета». В прод он ещё не попадал.

Проект работает на **старой версии Webasyst**, поэтому решения должны использовать только стабильный API фреймворка без новых возможностей.

Твоя задача: **подготовить код к мержу**.

## Бизнес-требования

1. Раздел заказов в личном кабинете доступен **только авторизованным** клиентам.
2. Клиент видит и редактирует **только свои** заказы.
3. Редактировать можно только заказ в статусе `new`. Заказ в статусе `paid` или `cancelled` менять нельзя.
4. Клиент может изменить **только название** заказа (`title`).
5. Сотрудник видит заказы в бэкенде **только с правом «Просмотр заказов клиентов»**.
6. Деньги хранятся и считаются **в копейках** (целые числа). API отдаёт сумму заказа в копейках.

## Что нужно сделать

- Найти и исправить проблемы в PHP-коде, шаблоне и JS.
- Привести код в соответствие с бизнес-требованиями.
- Объяснить, как ты проверишь, что исправления работают.

Всё за 20 минут сделать не обязательно. Расставь приоритеты: начни с самого важного.

## Правила

- Можно и нужно пользоваться **Claude Code, Codex** или другим AI-инструментом, которым ты обычно работаешь.
- Покажи экран с терминалом и окном агента.
- Проговаривай вслух, что делаешь и почему.
